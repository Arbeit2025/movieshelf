# おうち映画棚（movieshelf）

観た映画・観たい映画を「棚」に並べて眺める視聴メモです。映画を登録すると、棚のようなグリッド（カード）表示で一覧できます。外部 API は使わず、データは SQLite に保存します。

着想元：ancaferro の kodi.kino.pub（Kodi 向けアドオン）から発想を得た、フォロワー発想の小ツールです。

## 機能

- **映画の登録**：タイトル（必須）、状態（観たい／観た）、評価（1〜5、任意）、公開年（任意）、メモ（任意）を登録できます。
- **棚表示**：登録した映画はカード形式のグリッドで表示されます。評価は ★ で表示され、状態はバッジ（観たい＝青、観た＝緑）で区別されます。
- **状態で絞り込み**：全部／観たい／観た で棚を絞り込めます。
- **削除**：カードの「削除」ボタンから棚から外せます（確認ダイアログつき）。
- **バリデーション**：評価は 1〜5 の範囲外（0、6、数値以外）を受け付けません。その場合は登録自体が行われません。タイトルが空の場合も登録されません。ユーザー入力は HTML エスケープして表示します。

DB のパスは環境変数 `MOVIESHELF_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- ログイン機能はありません。
- **Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。** 大事な視聴記録は別途控えを取る前提で使ってください。
- ポスター画像や映画情報の自動取得はしません。すべて手入力のメモです。
